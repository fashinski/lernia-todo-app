# My ToDo - Lernia

This is my ToDo app for A2 submission 1.
I continued the app from the previous course and styled it using the teacher's
reference video and the instructions from lesson 3.

The app uses plain HTML, CSS and JavaScript in separate files.

## What I can do

- Add a task with the OK button or Enter.
- Click a task to mark it as completed, then click again to undo it.
- Delete a task with the small basket button.
- See how many tasks are completed.

The tasks are stored in an array of objects. The array and the list stay in sync
when I complete, undo or delete a task.

## Styling and animations

I matched the pink gradient, white panel, heading and task layout from the video.
The panel moves down from above and fades in. New tasks fade in while moving
upwards. Completed text fades to grey. Empty input shows a blinking red message.

## Run it

Open `index.html` with Live Server in VS Code. No packages need to be installed.
